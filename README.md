Сессионный проект МИФИ 2026: РЕД ОС 8, nginx, безопасность

Система: РЕД ОС 8.0.3 (Standard Server Minimal, без графики), установлена в VirtualBox, к виртуальной машине подключён второй диск на 2 ГБ. Всё выполнял в командной строке от своего пользователя gleb_adm через sudo, учётная запись root заблокирована. Номер студента: 372260.

1.1. Настройка сети. В установщике для интерфейса enp0s3 включил получение адреса по DHCP и автоматическое подключение при загрузке. Система получила адрес 10.0.2.15.

1.2. Имя хоста. В установщике задал имя mephi-2026.domain.local, после установки проверил командой hostnamectl.

1.3. Проверка связи. Выполнил ping -c 4 8.8.8.8 и сохранил результат в ping.out, потерь пакетов нет.

2.1. Обновление системы. Выполнил sudo dnf upgrade -y, транзакция обновления видна в dnf.out.

2.2. Установка пакетов. Командой dnf install установил nginx и libcap-ng-utils, а также policycoreutils-python-utils, который нужен для команды semanage при настройке SELinux.

2.3. Установка tcpdump из RPM-файла. Скачал пакет командой dnf download tcpdump --destdir /tmp. Вместе с нужной 64-битной версией скачалась 32-битная (i686), которая требует 32-битные библиотеки, поэтому её удалил. Установил пакет командой rpm -ivh /tmp/tcpdump-4.99.5-1.red80.x86_64.rpm. Установка через rpm не попадает в историю dnf, поэтому её видно в history.out.

3.1. Файловая система. На втором диске /dev/sdb создал через fdisk один раздел на весь диск и отформатировал его в ext4 с меткой тома: mkfs.ext4 -L MEPHI_WEB /dev/sdb1.

3.2. Монтирование. Создал каталог /mephi-web и добавил в /etc/fstab строку LABEL=MEPHI_WEB /mephi-web ext4 defaults 0 2, то есть раздел подключается по метке тома. Смонтировал командой mount -a и проверил после перезагрузки командой findmnt.

4.1. Веб-сервер. Запустил nginx и включил автозапуск командой systemctl enable --now nginx. После перезагрузки сервис в состоянии active и enabled.

4.2. Журнал. Сообщения журнала nginx за текущую загрузку сохранил командой journalctl -u nginx -b в файл journalctl.out.

5.1. Права на каталог проекта. Создал группу developers для разработчиков и группу curators с GID 4444. Создал пользователей user1, user2, user3 с UID 5501, 5502, 5503 в группе developers и кураторов curator1, curator2 в группе curators. Каталогу /data/mephi-2026 назначил владельца root и группу developers, права 2770: бит setgid нужен, чтобы все новые файлы получали группу developers. Чтобы права действовали и на файлы, которые будут созданы потом, настроил ACL по умолчанию: разработчикам чтение и запись, кураторам только чтение, остальным ничего. Проверил на практике: user2 изменил файл, созданный user1, куратор файл прочитал, но записать не смог, посторонний пользователь получил отказ в доступе.

5.2. Привилегии tcpdump. В РЕД ОС 8 у файла /usr/sbin/tcpdump бита set-UID изначально нет. До настройки user1 получал ошибку You don't have permission to capture on that device. Выдал файлу только нужные привилегии командой setcap cap_net_raw,cap_net_admin=eip /usr/sbin/tcpdump, после этого sudo -u user1 tcpdump -c 5 -i enp0s3 успешно захватывает пакеты.

5.3. SELinux. Проверил, что SELinux работает в режиме Enforcing. В /etc/nginx/nginx.conf заменил корневой каталог на root /mephi-web. Сначала сервер выдавал ошибку 403: у нового раздела была метка unlabeled_t, и ausearch показал, что SELinux запретил процессу nginx доступ. Исправил постоянно, через правило политики: semanage fcontext -a -t httpd_sys_content_t "/mephi-web(/.*)?" и restorecon -Rv /mephi-web. После этого страница открылась.

6.1. Запрет входа кураторам. Кураторам назначил оболочку /sbin/nologin командой usermod -s. При попытке su - curator1 система отвечает This account is currently not available, у user1, user2, user3 осталась оболочка /bin/bash.

6.2. Пароли. В /etc/login.defs установил PASS_MAX_DAYS 90 до создания пользователей, поэтому все новые пользователи получили срок действия пароля 90 дней. Своему пользователю gleb_adm, созданному раньше, выставил срок командой chage -M 90. В /etc/security/pwquality.conf задал minlen = 12, модуль pam_pwquality подключён в системе.

7.1. Веб-страница. Создал файл /mephi-web/index.html с текстом Hello from Student: 372260.

7.2. Проверка. Команда curl http://localhost/ возвращает Hello from Student: 372260. После перезагрузки системы проверил это повторно.

8. Публикация. Пакета gh в репозиториях РЕД ОС нет, поэтому подключился к виртуальной машине по SSH из Windows через проброс порта 2222 на 22 в VirtualBox и отправил файлы командой git push с токеном доступа. Скриншот загрузил через сайт GitHub.

Все настройки проверил после перезагрузки системы.
